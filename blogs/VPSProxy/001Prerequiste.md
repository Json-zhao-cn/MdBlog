# From Zero to One: Building a Personal VPS

## 1. Background
This project documents the complete process of building a personal VPS-based proxy service from scratch.

The primary objectives are:

- Learn Linux server administration.
- Learn 3x-ui deployment and configuration.
- Configure Cloudflare DNS and TLS certificates.
- Build a secure and maintainable VLESS service.
- Document the entire deployment process for future reference.

This guide assumes the reader has basic IT knowledge and wants to deploy a personal VPS for learning purposes.

## Project Scope

This project is intended for personal learning and educational purposes.

Usage rules:

1. The service is for personal or family use only.
2. Do not use it for commercial purposes.
3. Do not share accounts publicly.
4. Keep the number of users small to ensure stable performance.
5. Comply with applicable laws and regulations in your jurisdiction.
